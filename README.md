# Zakon za bogate

Spletna stran **zakonzabogate.si** — interaktivna primerjava neto plač in razvojne kapice iz interventnega zakona (ZIURS).

- `index.html` — celotna stran (HTML, CSS in JS v eni datoteki, brez gradnje)
- `assets/` — logotip in fotografija

Stran se odpre na dnu; uporabnik se premika navzgor do Brodnjakove kapice, nad njo sta graf stroškov in tabela z metodologijo ter viri.

Lokalni ogled: odpri `index.html` v brskalniku ali zaženi `python -m http.server` v tej mapi.
